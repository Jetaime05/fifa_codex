# Codex bootstrap instructions

Before planning, editing, reviewing, spawning sub-agents, or running project commands, read [`CODEX.md`](./CODEX.md) completely.

Treat `CODEX.md` as the project's handoff memory. Verify its recorded status against `git status`, `git log -1`, and the relevant section of `PROJECT_PLAN.md`. If the repository is newer than the handoff, update the handoff before continuing.

After completing or accepting a phase, update `CODEX.md` in the same change so a new Codex account or task can continue without relying on conversation history.
