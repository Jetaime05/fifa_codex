`Pitch11` is not just a football game. It is a full football platform: a realistic 3D 11v11 football experience, a squad-building card game, a tactical manager simulator, an AI research playground, an online competitive arena, a creator ecosystem, and a live-service football universe.

The project begins as a web-based proof of concept, then expands into a mobile-first football game with:

- Realistic 3D match gameplay.

- Smart AI opponents.
- Online PvP.
- Squad building.
- Player cards.
- Career mode.
- Clubs/guilds.
- Events and seasons.
- Market and economy.
- Replay and esports tools.
- AI training and self-play simulation.
- Creator tools for stadiums, kits, tactics, and custom tournaments.

The long-term dream is to build a football game that feels like the player is not only controlling a match, but running an entire football identity.

## 7. Architecture Principles

1. **Rendering is replaceable.**
   Three.js renders the current POC, but match logic should not depend on Three.js.

2. **Simulation is deterministic where possible.**
   The game should support input logs, replays, tests, and future server authority.

3. **Data drives behavior.**
   Players, tactics, formations, AI profiles, cards, and events should live in data configs.

4. **Offline first, online later.**
   A great offline AI game is the foundation for online PvP.

5. **Every system must serve football feel.**
   Meta systems are valuable only if the match itself feels worth playing.
